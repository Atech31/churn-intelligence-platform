# 🛒 E-Commerce Customer Retention & Churn Analytics

An end-to-end data analytics project examining customer purchase behaviors, calculating Recency-Frequency-Monetary (RFM) scores, and predicting customer churn using SQL and Machine Learning.

## 📌 Features
* **Automated Data Generation:** Synthetic data pipeline generating normalized relational schemas.
* **SQL Analytics Engine:** In-memory SQLite aggregation views for purchase frequency and recency.
* **Predictive Modeling:** Machine Learning Random Forest classifier predicting churn risk.
* **Interactive Visualizations:** HTML scatter plot showing customer spend distributions.

## 🛠️ Execution
1. Generate Data: `python generate_datasets.py`
2. Run Analysis: `python churn_analysis.py`
